# Template Design Specifications

## Wedding Design Language
- **Elegant Floral:** Soft gradients, botanical framing, serif typography.
- **Cinematic Vintage:** Film grain, perforated edges, scene-based layout, warm highlights.
- **Luxury Geometric:** Arabesque/Islamic geometric patterns, gold/teal palette, symmetrical layout.
- **Playful Modern:** Vibrant colors, organic shapes, pixel art (Game category).
- **Adat 3D/Papercraft:** 3D cutout/silhouette effect, paper texture, traditional joglo elements.

## Common Features
- Cover screen (with music & entrance animation).
- Countdown timer (shared component).
- Event details (marriage contract + reception).
- Gallery (Stills/Film strips).
- Live streaming integration.
- RSVP & Guestbook.
- Digital Gift (Amplop digital).

## Responsive Strategy
- Mobile-first: 100vw layout for hero, cards stacking.
- Desktop: Grid layout for gallery, side-by-side event sections.
